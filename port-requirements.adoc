= Port requirements for NetApp Data Migrator
:icons: font
:imagesdir: ./media/

[.lead]
You need to ensure that certain TCP ports are open to allow communication between the control plane virtual machines (VMs) and worker VMs in NetApp Data Migrator.

== Control plane ports

[cols="1,1,1,1a" options="header"]
|===
|Service |TCP port | From | To

|Temporal | 7233 or 7234, 8080 | Workers and clients (browser or any external client) | Control plane
|Redis | 6379 | Workers and clients (browser or any external client) | Control plane
|NDM Application | 443 | Workers and clients (browser or any external client) | Control plane
|Grafana | 3000 | Browser | Control plane
|Isilon management console | 443, 8080 | Control plane | Isilon management console
|Outbound to storage | 2049 | Control plane | NFS servers

*Note*: Include TCP or UDP port 111 if you need the portmapper service for Remote Procedure Calls.
|Outbound to storage | 445 | Control plane | SMB servers
|===

== Worker ports

[cols="1,1,1,1a" options="header"]
|===
|Service |TCP port | From | To

|Outbound to storage | 2049 | Worker | NFS servers

*Note*: Include TCP or UDP port 111 if you need the portmapper service for Remote Procedure Calls.
|Outbound to storage | 445 | Worker | SMB servers
|===
